# 新版 AI 聊天（阶段 A）

入口为 `/AI/ChatNew`，已由 Umi 约定式路由注册。原 `/AI/Chat` 联调页顶部也提供新版入口。

正式菜单编码为 `ChatNew`，名称为“AI 聊天（新版）”，独立于旧聊天入口。新建库的两份 RBAC 初始化脚本均已包含该菜单，并默认分配给已有
admin 角色。已有库在 RBAC
数据库执行[菜单迁移脚本](../../../../../deploy/mysql/sql/migrations/20261011-ai-chat-new-menu.sql)
，可重复执行；随后重新登录以刷新账号菜单。其他角色由菜单／角色管理显式分配。若已手工配置相同路由的不同菜单编码，迁移保留原配置，应给该编码分配展示权限。菜单权限只控制入口展示，AI
scope、模型与预算仍由后端校验。

## 使用流程

1. 登录后，全局顶部和聊天页共用工作空间选择器及状态。已有用户读取目录和偏好；偏好明确返回 `PLATFORM_NOT_FOUND`
   时，以独立幂等操作初始化真实个人默认空间。其他失败不触发初始化，未确认操作不自动重发，可在面板确认原操作。目录使用真实分页，筛选只针对当前页。
2. 选择空间，创建或选择会话。公共空间创建只需名称和描述；基础面板支持改名／描述、收藏及设置／清除启动空间，入口由后端动作检查决定。主动选择更新最近访问偏好，保留其他偏好字段。
3. 数据库模式下，先完成一次平台配置导入，新建空间按已发布模板自动准备模型及独立预算；进入已有公共空间时先校验并准备配置，随后加载聊天。
   顶部“平台 AI 配置”维护模型与新空间模板，设置中的“空间 AI 配置”维护当前范围。部署与权限说明见
   [数据库配置迁移](../../../../../backend/arte-app/docs/PLATFORM_AI_CONTROL.md)。部署默认仍为 FIXED，原合法 AI scope
   可通过“连接已有 AI 工作空间”访问；后端继续检查授权。
4. 单模型、单兼容预算时自动采用推荐额度。多项、失效缓存或权限错误时，打开“模型管理”，明确选择兼容配置并应用。所有模型入口使用同一份配置草稿和已应用配置。
5. Enter 发送、Shift+Enter 换行；中文输入法确认不会发送。活动调用和未确认操作期间可以编辑下一条草稿。原操作重试保持原参数；重新生成会创建原问题的新候选调用，可能产生费用。

## 恢复与隔离

- 浏览器键包含当前账号、租户、空间、会话或预算目标和格式版本。配置、置顶及栏宽属于 `localStorage`
  偏好；会话选择、草稿、公共空间选择及未确认操作放在当前标签的 `sessionStorage`。
- 发送、创建会话、重新生成、停止、核对，以及公共空间初始化／创建／改名／偏好更新，都在提交前保存原请求与独立幂等键。网络、408、5xx、AI／公共空间
  幂等内容冲突保留快照；刷新不会自动执行新的写请求。
- 已知受理 ID 时读取原调用状态、结果与流；未知受理结果时通过原请求、原键确认。核对还可只查询原回执。重试旧问题不会清除另行编辑的新草稿。
- 公共空间操作已知 operationId 时查询原回执，不用客户端操作键冒充服务端
  ID；版本冲突刷新后保留输入，幂等冲突保留原快照。创建／改名表单固定打开时的目标，不因另一个入口切换空间而换租户。
- 切换会话／空间会取消前端观察并忽略迟到响应，后端执行继续。返回后恢复原会话；不存在的已保存会话会清除选择，原公共空间失去访问权时校验并回退真实个人默认空间。
- 其他标签更新配置只提示重新校验，不改变当前配置或未确认请求。退出登录清理该账号的标签内草稿和操作记录，停止观察；保留本地配置、置顶和栏宽偏好。
- 操作快照不可读或损坏时禁止创建竞争操作；保存失败时显示提示。未确认请求无法保存时阻止页面内切换，离开页面时提示。关闭标签、清理浏览器存储后不能承诺恢复标签内记录。
- 不保存身份令牌、供应商密钥或流式结果副本。流式片段只作预览，最终输出以服务端为准。历史与已收敛调用缓存有界，未收敛执行保留发送门闩。

## 实现组织

- `src/features/ainew` 共享配置发现／校验、会话、执行观察、恢复、费用核对和 Markdown；联调页通过重新导出继续使用共享逻辑。
- `src/features/workspace`
  提供公共选择器和同账号、同标签的共享目录、详情、偏好及操作协调。全局顶部和页面入口共用请求；当前模块注册切换保护，其他入口不能绕过聊天草稿保护。退出／账户切换清理原账户的空间状态并取消请求。
- `src/services/platform/workspace.ts` 使用 `/arte/workspace/*`。公共角色／状态采用数值线协议，访问检查原因采用字符串，不以角色推断
  AI 执行权。
- 首批 View 没有组织名称／托管者字段，当前显示真实 tenantId 表示归属，不猜测类型或名称。跨模块共享当前 scope 不等于已经迁移旧文章或
  AI 的归属与授权。
- 桌面可调整栏宽；平板将设置移入抽屉；手机将列表和设置移入抽屉。始终只挂载一个聊天实例，跨断点保留配置草稿。
- Markdown 支持 GFM 表格、代码和复制，跳过原始 HTML，过滤危险链接。候选浏览只改变显示，后续上下文仍由服务器选择。

## 新空间与 AI 访问提示

数据库模式完成首次导入后，公共空间创建会按已批准模板开通独立配置；FIXED 模式仍须原范围授权。`listConversations` 返回 403
时，页面呈现“此空间的 AI 功能暂不可用”， 停用新建会话和筛选入口，提供实际空间选择器、开通说明与“重新检查”。不再同时显示红色列表加载失败和可直接开始聊天的空状态。
重新检查会重新读取当前空间的会话目录及可用模型，不创建会话或自动发送请求。

401 提示重新登录；网络／服务失败保留加载重试；已授权的空列表显示暂无会话。仅模型发现被拒绝或无可用配置时，
已获授权的会话仍可阅读，发送继续受现有配置和后端授权约束。通用 403 不被解释为模型未配置；说明中引导管理员分别确认权限、
模型和预算，诊断所需的租户／空间标识放在可展开的支持信息中。切换空间继续沿用草稿保护和旧请求取消机制。

# 新版 AI 聊天（阶段 A）

入口为 `/AI/ChatNew`。原 `/AI/Chat` 联调页顶部也提供新版入口；生产菜单如由后台维护，可将菜单地址配置为该路由。本批不修改菜单权限数据。

## 使用流程

1. 登录并打开公共工作空间选择器。已有用户读取目录和偏好；尚未初始化时，显式点击“初始化个人默认空间”。目录使用真实分页，筛选只针对当前页。
2. 选择空间，创建或选择会话。公共空间创建只需名称和描述，入口由后端基础权限检查决定。收藏和启动空间通过公共偏好接口保存。
3. 当前 AI 仍走 FIXED 授权。使用原合法 AI scope 时，点击“连接已有 AI 工作空间”，填写真实租户和空间
   ID；页面显示当前范围，后端检查授权。公共空间不会自动获得模型、预算或原 AI 历史。
4. 单模型、单兼容预算时自动采用推荐额度。多项、失效缓存或权限错误时，打开“模型管理”，明确选择兼容配置并应用。所有模型入口使用同一份配置草稿和已应用配置。
5. Enter 发送、Shift+Enter 换行；中文输入法确认不会发送。活动调用和未确认操作期间可以编辑下一条草稿。原操作重试保持原参数；重新生成会创建原问题的新候选调用，可能产生费用。

## 恢复与隔离

- 浏览器键包含当前账号、租户、空间、会话或预算目标和格式版本。配置、置顶及栏宽属于 `localStorage`
  偏好；会话选择、草稿、公共空间选择及未确认操作放在当前标签的 `sessionStorage`。
- 发送、创建会话、重新生成、停止、核对，以及公共空间初始化／创建／偏好更新，都在提交前保存原请求与独立幂等键。网络、408、5xx、AI
  幂等内容冲突保留快照；刷新不会自动执行新的写请求。
- 已知受理 ID 时读取原调用状态、结果与流；未知受理结果时通过原请求、原键确认。核对还可只查询原回执。重试旧问题不会清除另行编辑的新草稿。
- 切换会话／空间会取消前端观察并忽略迟到响应，后端执行继续。返回后恢复原会话；不存在的已保存会话会清除选择，原公共空间失去访问权时校验并回退真实个人默认空间。
- 其他标签更新配置只提示重新校验，不改变当前配置或未确认请求。退出登录清理该账号的标签内草稿和操作记录，停止观察；保留本地配置、置顶和栏宽偏好。
- 操作快照不可读或损坏时禁止创建竞争操作；保存失败时显示提示。未确认请求无法保存时阻止页面内切换，离开页面时提示。关闭标签、清理浏览器存储后不能承诺恢复标签内记录。
- 不保存身份令牌、供应商密钥或流式结果副本。流式片段只作预览，最终输出以服务端为准。历史与已收敛调用缓存有界，未收敛执行保留发送门闩。

## 实现组织

- `src/features/ainew` 共享配置发现／校验、会话、执行观察、恢复、费用核对和 Markdown；联调页通过重新导出继续使用共享逻辑。
- `src/features/workspace` 提供公共选择器和同账号、同标签的共享当前空间，其他模块可直接复用。
- `src/services/platform/workspace.ts` 使用 `/arte/workspace/*`。公共角色／状态采用数值线协议，访问检查原因采用字符串，不以角色推断
  AI 执行权。
- 桌面可调整栏宽；平板将设置移入抽屉；手机将列表和设置移入抽屉。始终只挂载一个聊天实例，跨断点保留配置草稿。
- Markdown 支持 GFM 表格、代码和复制，跳过原始 HTML，过滤危险链接。候选浏览只改变显示，后续上下文仍由服务器选择。

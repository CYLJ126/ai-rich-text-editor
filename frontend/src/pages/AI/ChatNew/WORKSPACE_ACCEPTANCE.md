## 接入契约

- 聊天读取 `useCurrentWorkspace(userId)`，全局顶部和聊天入口共享同标签、同账号状态。聊天实例按账号及完整 scope
  挂载；空间改变后取消旧观察，目标空间重新加载自己的数据。
- 模型发现、会话目录／详情、历史、预算和发送请求均携带当前 scope；预算 ID 或会话 ID 相同也不能省略租户、空间范围。
- 公共空间资格与 AI FIXED 授权分别由后端检查。空模型目录或 AI 授权拒绝时显示提示，禁止借用上一空间的模型、预算和配置。
- “连接已有 AI 工作空间”只用于显式 FIXED 过渡，页面展示实际范围。公共选择失败保留这项显式连接；选择成功才退出显式连接，采用统一公共空间。
- 目标空间拒绝访问不等于整个目录失效。当前已验证空间仍可用时保留选择能力；未认证或整个目录不可访问时继续限制选择。
- 未确认提交保留原 scope、参数和幂等键。返回原空间恢复观察或提供原操作重试；刷新／导航／切换不自动创建新的提交，也不调用后端停止接口代替空间切换。

契约测试验证。

| 验收项           | 检查内容                                                              |
|------------------|-----------------------------------------------------------------------|
| scope 一致       | 目标空间下的发现、会话、历史、预算和发送均使用完整目标 scope          |
| FIXED 过渡       | 失败公共选择保留显式连接，成功选择后退出，不自动切换授权模式          |
| 目标空间拒绝     | 403 不误锁整个合法目录，失败后仍可选择或重试；不会清除显式 FIXED 连接 |
| 刷新恢复         | 重新挂载保留当前空间、原请求／原键及独立的新草稿，不自动提交          |
| 跨模块导航       | 在其他模块选择空间，回到聊天采用该空间；原空间草稿独立恢复            |
| 多标签隔离       | 其他标签的当前空间／配置偏好事件不改变本标签选择及草稿                |
| 失效启动偏好     | 先校验并回退真实默认空间，不向失效 scope 发起 AI 请求                 |

| 迟到响应         | 取消旧模型、会话、历史和预算请求；迟到成功／错误不覆盖目标空间        |
| 相同会话 ID      | 不同空间即使返回同一会话 ID，历史与预算也不能混用                     |
| 调用观察         | 切换取消旧 invocation 观察，返回只恢复原 scope 的原调用，不重复提交   |

## 浏览器与真实环境

2026-10-11 已使用隔离模拟 HTTP 在真实浏览器检查刷新、空间改名、空配置提示、跨模块导航及两个标签各自保持选择。本轮补充上述页面集成回归；不把测试组件重新挂载当作真实浏览器的整页刷新。

真实后端／供应商联调尚未执行。需要运行环境具备公共空间 HTTP、登录身份及一个合法 FIXED AI scope（发布引用、可用预算和供应商凭据），另有可访问但没有
AI 配置的公共空间。运行环境的复验顺序如下：

1. 首次进入取得服务端真实个人默认空间；在可访问空间目录选择空间，并在网络面板核对后续请求 scope。
2. 显式连接已有合法 FIXED scope，检查发现／预算／历史；按环境的测试模型完成一次受控发送，再检查调用和费用结果。
3. 切换至无 AI 配置空间，确认提示和发送限制，不能看到或使用原空间模型、预算及历史。
4. 在原空间编辑草稿和配置草稿，检查顶部切换保护；刷新后恢复已保存草稿和原操作，不自动重复提交。
5. 同账号打开第二标签；一个标签切换空间后，另一个标签和刷新后的当前选择保持独立。
6. 设置一个随后失去访问资格的启动空间，使用新标签验证回退；延迟旧空间请求并切换，验证其响应不会覆盖目标空间。

公共资源授权接入 AI、动态模型／助手管理及成员治理不属于本轮。公共选择不会迁移旧资源，也不新增“切换空间”后端接口。

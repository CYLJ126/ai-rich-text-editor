# AI 对话测试页面：第三步

约定式路由：`/AI/Chat`。登录后访问，菜单沿用现有 `/AI/Chat` / `AI.Chat` 配置。

应用测试配置（或从本地恢复配置）后，自动查询当前租户和工作空间的会话列表，每页 20
条。支持翻页、刷新，以及加载中、空列表、请求失败状态。未应用的表单修改不参与请求；请应用修改后再操作会话。

“新建会话”打开标题输入框，标题必填且最多 256 个字符。创建请求只传 scope 和 title，暂不传
chatProfile/resources，也不触发模型调用或预算扣费。创建成功后自动查询并选择该会话的最新详情，同时刷新第一页；后端列表排序不保证新会话出现在第一页，当前选择与列表页相互独立。

点击列表项调用详情接口，显示标题、ID、最新版本、状态和时间。快速选择、刷新或切换工作空间时，取消旧请求并忽略迟到响应。应用不同租户/工作空间，或清除配置，会清空当前会话与创建弹窗；仅修改生成参数不会清空当前会话。

每次新建生成一个幂等键，禁止重复提交。创建失败后保留原始标题和键，“重试创建”复用同一请求；关闭并重新打开弹窗仍可重试。刷新页面、切换工作空间或离开页面会丢失重试信息，如果此前请求结果不明确，请先刷新列表确认是否已经创建成功。

HTTP/业务错误在对应区域展示，包含后端描述、状态码和业务码；401 提示重新登录，403 提示检查接口权限与租户/工作空间授权。列表、详情可独立重试。

配置保存在 `arte.ai-new.chat.config.v1`，继续支持校验、恢复及清除。Capability/Binding/预算等引用仍需填写实际后端配置，创建会话仅验证会话请求涉及的授权，不代表模型与预算链路已验证。

发送消息、历史记录、执行状态与预算查询留待后续步骤；发送按钮仍禁用。所有 HTTP 封装复用 `src/services/arte-ai`。

验证：`npm test -- src/pages/AI/Chat src/services/arte-ai`，覆盖配置、会话创建与选择、分页、错误重试、幂等键复用和请求竞态。真实后端联调还需启动服务并使用已授权账号。

# AI 对话测试页面：第二步

约定式路由：`/AI/Chat`，登录后可直接访问。若需要侧边栏入口，在现有菜单管理中配置菜单 URL `/AI/Chat`、菜单编码 `AI.Chat`
并授权给对应角色；本步不改动数据库菜单。

本步实现会话列表、消息/历史区域、执行状态/预算占位和测试配置表单。配置包含租户/工作空间、capability/binding 的 ID
与固定版本、预算账户引用、输入/输出 Token 上限、超时和可选 Temperature/Top P。

点击“应用配置”后，校验成功的值成为当前配置，并以 `arte.ai-new.chat.config.v1`
保存到浏览器本地。刷新后恢复；“清除配置”清除当前配置及缓存、恢复空引用和初始数值。未应用的修改不覆盖当前配置。存储损坏、版本不兼容或浏览器禁止存储时会显示提示。

本地校验与后端可用性验证分开：引用必须来自实际发布配置，固定版本不能为 `latest`；数值为 HTTP 契约允许的范围，后端仍校验发布配置和预算限制。初始
Token/超时值可以修改；Temperature/Top P 留空代表使用发布默认值。

当前会话创建、列表查询、历史查询及发送按钮为占位；本步不发起新 AI 请求。下一步接入会话创建、列表与选择，再逐步接入消息、多轮历史和预算查询。请求代码继续放在
`src/services/arte-ai`。

验证：`npm test -- src/pages/AI/Chat src/services/arte-ai`。

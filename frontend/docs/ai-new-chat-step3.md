# 新聊天第三步：执行控制与异常处理

本文记录第三步范围；当前页面已继续完成 [第四步使用体验与第一版验收准备](ai-new-chat-step4.md)。

在 `/AI/Chat` 的 [最小聊天闭环](ai-new-chat-step2.md) 上加入请求停止、重新生成与异常分类，沿用现有聊天／模型控制接口。
没有增加表、修改旧 AI 路径或自动开启模型配置。真实环境仍按第一步和后端模型／聊天服务说明配置。

## 请求停止

- 仅对已关联执行且仍为 ACCEPTED／RUNNING 的最新提交开放，调用 `POST /conversations/{id}/turns/{turnId}/cancel`
  ，使用当前认证与完整空间作用域。
- 分别展示 REQUEST_ACCEPTED、CANCELLING、CANCELLED、UNCONFIRMED、ALREADY_COMPLETED 回执。回执不是聊天执行终态，不把本地 HTTP
  结束当作模型已停止。
- 受理停止请求后继续查询权威历史，不提前释放会话；禁止新消息、当前会话命名和删除，仍可浏览和新建其他会话。查询确认终态后恢复操作。
- 已外发的执行仍可能成为 OUTCOME_UNKNOWN 并产生费用。回执丢失不自动重试；UNCONFIRMED 时先查询，再由用户明确请求停止同一执行。
- 当前最小模型执行仍依赖既有单实例执行器。无法定位活跃任务时返回 UNCONFIRMED，不伪造远端停止或自动创建新执行。刷新后从历史观察结果，本地回执不持久化为执行状态。
- PREPARING／READY 尚无模型执行引用，不能取消模型。没有本地原请求时展示核对编号及管理员核对提示，不换键重发。

## 重新生成

- 只对最新提交开放，要求已有执行、执行已结束、结果确定、无未完成提交，且当前模型绑定与会话一致。OUTCOME_UNKNOWN 或错误信封的结果确定性为
  UNKNOWN 时不开放。
- 重新展示实际目的地、原问题和原上下文用途，说明可能再次外发／计费、原回答保留，每次必须明确确认。
- 调用 `POST /conversations/{id}/regenerate`，发送租户／空间、当前预期版本、originalTurnId、确认字段和新
  Idempotency-Key。预览文本不作为重新生成输入发送；原问题、历史和生成参数由服务端确定。
- 新结果作为独立提交呈现，保留此前回答与未发送草稿。服务端不会把重新生成当作新的用户问答轮次拼装上下文。
- 响应丢失时暂存原操作种类、目标提交、预期版本、预览文本和键。刷新后只明确重放同一操作，不转换成普通消息、不更新版本或更换键；兼容第二步没有操作种类字段的普通待核对请求。
- 并发版本冲突、目标被后续问题取代、权限或绑定变化，仍由服务端实时拒绝。页面不改写原请求自动重试。

## 异常与恢复

稳定提示区分预算不足、预算策略缺失、容量／频率限制、版本冲突、幂等冲突、策略不可用、不支持的操作、执行期限、网络中断、请求等待超时和结果未知。
RATE_LIMITED 只有 failureStage 为 budget 才解释为预算不足，不把执行容量不足误报成欠费。

- 新模块 HTTP 请求等待上限为 30 秒。浏览器等待超时不能推断服务端未受理或模型终态；原请求继续保留，先查询再明确重放。
- 有未完成提交、原请求待核对或首次历史尚未验证时，锁定当前会话命名和删除；后端仍以权威占位与预期版本校验其他客户端竞争。
- 权限失败后隐藏旧消息，停止自动观察。明确重新查询期间不闪回缓存，只有新的授权查询成功后恢复。退出／切换账户及迟到响应继续遵守第二步隔离规则。
- 查询失败时不显示缓存回答冒充最新结果、不派发新请求。观察最多 5 分钟，暂停不改变执行终态，可明确重新查询继续观察。
- 失败、未关联和结果未知记录显示核对编号，便于管理员查询原提交／执行。只解释稳定错误，不回显供应商正文、自由异常信息或凭据。

## 手工验收

1. 生成中请求停止：只有一次控制请求，仍锁定会话，回执与执行状态分别显示；最终成功、取消或结果未知以历史为准。
2. 制造停止回执丢失／UNCONFIRMED：先查询，不自动取消重试或新建模型调用；结果未知时不能直接重新生成。
3. 两轮对话完成后重新生成：仅最新提交有入口。取消弹窗不调用；明确确认后新建独立执行，旧回答及草稿保留。
4. 制造重新生成响应丢失并刷新：重放端点、目标、预期版本和键保持不变，不增加同键提交或预算预留。
5. 制造预算不足、缺少配置、限流或版本冲突：提示与原因一致，保留输入，不自动提交。
6. 撤销控制或查询权限后重新查询：等待期间不闪回旧消息；切换账号／会话后，迟到控制响应不恢复旧界面。

自动验证使用真实 Ant Design 与 React Query、模拟 HTTP；后端使用生产 JSON 转换器、实际身份／权限及 H2，供应商仍为测试适配器。
没有执行实际数据库脚本或调用真实供应商，生产数据库、登录菜单、浏览器视觉与真实模型停止行为需在部署环境验收。

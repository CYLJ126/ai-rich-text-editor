# M4 页面夹具

在 frontend 目录执行 `node scripts/model-m4-browser/server.mjs`，打开
`http://127.0.0.1:5244/Environment/Models`。停止时使用 Ctrl-C。

仅为内存契约／布局冒烟：使用正式模型页、工作空间页、目录选择器、统一管理器和治理编辑器，Umi 路由与接口由 shim 模拟。
不访问业务后端、数据库或供应商；重载页面清空内存。未模拟的动作显示拒绝，不能据此验证后端授权或真实结算。 没有真实密钥，不要在夹具输入业务凭据。

1. 查看三个 Tab 顺序，切换模型归属为租户，创建后直接看到资源详情及租户凭据字段。
2. 打开工作空间页面，点击 B 的“配置”；左侧当前空间仍为 A，偏好不变。
3. 显式首次准备，手动选择实际固定版本并保存，再独立选择费率、填写额度并保存；两个操作分别给出成功反馈。
4. 修改开关或规则后尝试离开，页面应保留草稿并拦截；“重新读取配置”可放弃本次草稿。
5. 在 390px 与默认宽屏检查换行、滚动、下拉和按钮；“查看内存状态”可核对模型选择及规则未互相覆盖。

后端新装、完整角色／故障／供应商回环和 model-a2-browser 全链路升级属于 M5，本夹具不替代它们。

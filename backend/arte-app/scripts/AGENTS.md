# MySQL DDL 编写约定

- 新增或修改表结构时，每个业务字段必须有完整、准确的中文 `COMMENT`，每张表必须有中文表 `COMMENT`，与现有脚本风格一致。
- 注释说明字段业务含义；涉及计量、状态、版本、引用或可空语义时，写清单位、状态含义、版本用途、关联对象或空值含义，不能只重复字段名。
- 使用 MySQL `COMMENT` 将说明写入数据库元数据，普通 SQL 行注释不能替代字段注释和表注释。
- 同一张表在初始化脚本和升级脚本中的定义及注释必须保持一致；沿用周边 SQL 的缩进和字段对齐方式。
- 交付前检查所有新增字段和表的注释完整性，不得为了节省时间或 Token 省略。

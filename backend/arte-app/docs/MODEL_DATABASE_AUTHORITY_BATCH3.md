# 数据库模型管理第三批：独立模型方案与费率发布

日期：2026-11-01。

## 交付内容

新增 `/AI/ModelPlans`“审核模型与费率”，可从模型管理及审核连接管理进入。
平台配置管理员直接选择数据库中的精确连接，填写新远端模型、上下文容量、币种和输入／输出单价，原子发布能力、绑定和费率。
无需预先存在同名文件模型、同名绑定、能力或费率；空目录先通过第一批页面登记连接即可。 已有个人模型草稿、本人凭据、连接验证和发布流程继续复用。

资格沿用平台 `aiConfiguration:manage`／admin，HTTP 与写事务分别复核；租户／空间角色不隐式获得费率审核权限。 个人发布仍要求当前
`model:publish`、本人凭据责任、成功验证及当前政策，不要求平台管理权限。 本批没有新增表或 DDL，复用 `arte_ai_control_revision`
、head、公共命令回执、审计和 Outbox。 租户级模型、跨空间使用和团队凭据用途仍属第四批，旧目录迁移仍属第五批。

后续[第四批](MODEL_DATABASE_AUTHORITY_BATCH4.md)已交付租户模型、同租户跨空间准入、授权页面及独立租户凭据用途；上述内容保留第三批当时边界。

## 页面操作

1. 平台管理员在 `/AI/Connections` 登记并启用受支持的审核连接。
2. 打开 `/AI/ModelPlans`，填写“方案标识”，选择精确连接版本，输入供应商实际远端模型名和审核的上下文容量。
3. 核对币种及每百万输入／输出 Token 价格，明确发布模型与费率版本。页面不提供默认免费价格，不自动换汇。
4. 按第二批页面核对模型所属租户与空间的个人凭据、协议、供应商和目的地主机政策。
5. 普通用户在“我可管理”创建私有模型，保存相同连接及远端模型名的草稿。草稿上下文不得超出审核容量，输出上限须小于草稿上下文。
6. 保存本人 API 密钥，验证当前连接，选择审核发布方案，发布新的个人固定版本。
7. 在聊天中重新加载配置，选择可用个人模型及其精确费率兼容预算，再应用配置。

连接验证只验证认证后的模型列表，不生成内容、不证明所有能力；发布使用十分钟内且依赖一致的成功验证。
审核页面声明文本、流式及可选用量报告，不新增工具调用或其他协议适配能力。 发布模型方案不会访问供应商；“声明支持用量报告”由审核者核实，执行时仍按实际证据结算。

## 独立预算配置

方案及个人模型发布都不创建预算、不重置额度或余额。发布成功但无兼容预算时，原状态接口仍提示 `NO_COMPATIBLE_BUDGET`。

使用既有 ChatNew“平台 AI 配置”中的“维护已发布模型与默认模板”，明确选中审核绑定、填写其费率对应预算上限并发布模板。
已准备的空间不会被新模板覆盖；还需在当前空间 AI 配置中选择已批准模型及其预算并保存。 未准备的空间按原流程准备
AI。主体预算账户仍由原按需准备流程建立，保留预留和已计费用。 额度提高继续要求既有平台配置资格；不能把模型发布当作额度审批。

该预算流程沿用原功能，没有在本批新增全局默认授权。实际模型使用继续经过模型 ACL、空间 AI 资格、两级政策、凭据用途和预算检查。

## 固定版本与费率语义

方案标识为 1～96 位字母、数字、点、下划线或连字符，首位为字母或数字。 服务端派生 `reviewed-<方案标识>` 的
binding／capability／rate，版本为本次目录修订 `db-vN`；客户端不能自报发布版本或凭据。
相同标识再次发布会追加新版本。修改目标、容量或价格不覆盖旧定义，旧个人发布与历史结算继续使用原精确费率。
历史审核方案保留可见，发布新版本不隐式撤销旧方案，也不自动升级个人发布、会话或预算；审核者应按实际允许的固定版本管理使用。
若需停止连接的新调用，沿用连接启停；若需停止某个人模型，沿用模型停用操作。

请求价格使用非负十进制字符串，最多 18 位整数和 18 位小数；不用浮点数、科学计数法或隐式舍入。 服务端以 Money
校验、规范化并保存。公开视图也返回十进制字符串；历史 Money 的较大整数金额仍可读取。 前端提供 CNY、USD、EUR；接口验证 ISO
币种，输入输出使用同一币种。价格为审核者录入值，不代表程序探测了供应商当前报价。 目录继续受既有单类最多 256
条定义的约束，不自动清理历史版本。

## HTTP 与事务

全部 POST，前缀 `/arte/workspace/ai`，沿用 ResultContext 和现有平台错误。

| 端点             | 请求                                                  | data                            |
|------------------|-------------------------------------------------------|---------------------------------|
| getModelPlans    | 无业务字段                                            | `{version, initialized, plans}` |
| publishModelPlan | `{expectedVersion, settings}`，携带 `Idempotency-Key` | 安全方案视图的命令回执          |

settings 包含 `id`、`connection` 精确引用、`remoteModel`、`contextWindowTokens`、`currency`、
`inputPerMillion`／`outputPerMillion` 字符串、`usageReporting`。 写请求及 settings
拒绝未知字段。响应只含固定引用、远端模型、容量与价格，不暴露连接凭据、地址或旧授权内容。

服务端锁定当前主体和目录 head，重查平台资格，核对 expectedVersion；连接必须存在、启用、使用已支持的 DeepSeek／Chat Completions
SSE 协议， 并满足当前部署 origin 上限。新能力使用原注册输入输出 Schema。 三类定义、目录指针、回执、审计与 Outbox
在原物理事务提交；任何一步失败全部回滚。 同键同内容重放重新核验当前资格、返回原结果，不生成竞争版本；目录变更返回版本冲突。

页面按账号保存严格白名单请求及原键。存储失败不提交，损坏记录保留并阻止新操作，刷新不自动重发。
网络、无法确认的成功响应、鉴权暂不可用及幂等内容冲突保留原操作供确认。 版本冲突保留完整草稿，明确重新读取后才能发布；重读连接和方案要求来自同一目录版本。
已确认发布但重读失败时只重读，不再次发布。新账号或已卸载页面的迟到响应被忽略。

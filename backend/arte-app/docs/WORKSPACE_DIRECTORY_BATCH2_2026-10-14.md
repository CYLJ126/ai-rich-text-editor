# 工作空间目录第二批交付（2026-10-14）

## 实现

步骤 4～6 完成：内部扫描改为强类型不可变边界及轻量键投影；新增有预算的公开浏览和独立计数接口；
空间选择器接入搜索、继续加载、空页续扫、过期重启及迟到响应保护。

内部 WorkspaceStore 不再注入 Redis 游标存储。SQL 只读取成员表的 tenant_id、workspace_id、workspace_created_sec、
workspace_created_nano，不 JOIN 空间表；成员创建键仍由联合外键约束。列表显示使用同批授权事实中的当前空间和角色。
旧页码和独立精确计数仍全量扫描，但内部不保存网络游标，进度检查只保留前一个唯一排序键，辅助内存不再随全部候选增长。

浏览核心返回 records、nextBoundary、exhausted，由 app 把内部边界转换为 Redis 中的 UUID token；公开响应不暴露边界。 token v2
绑定主体、规范化搜索、页大小和完整创建键，TTL 沿用现有配置。失效为 410，绑定错误为 400，基础设施故障为 503。
搜索根据已鉴权的当前名称匹配，不把候选快照当作允许读取的内容。

默认每次最多处理 200 个候选、4 批，批上限 100；首批 min (size*2,batchSize)，后续扩大批次。默认 1s 时间预算限制 后续批次启动，不取消在途
JDBC，也不包含调度排队；这是批次间工作预算，不是 HTTP 硬截止。 提前填满页面只越过已消费记录，余下候选下次重新读取和鉴权。预算耗尽允许空
records 和续扫 token。

前端首次启动仍读取偏好并验证选定／默认空间。续页和搜索不重复选择空间；搜索提交／刷新重置游标，过期提供明确重启按钮。
加载更多追加已验证摘要，拒绝重复范围和不推进的 token；AbortController 阻止过期响应覆盖新搜索或刷新。 前端已移除页码客户端、total
和 Pagination 依赖；旧后端页码 API 保留兼容，精确计数不会被选择器自动调用。

完整协议见 [改造契约](WORKSPACE_DIRECTORY_REDESIGN.md) 和 [HTTP 说明](PLATFORM_WORKSPACE_HTTP.md)。 物理时间列仍为秒／纳秒，本批不执行微秒
DDL 迁移，也不调整主体／租户排他门控。

## 可复测对照

使用与第一批相同的真实 Mapper／服务、8 工作线程和连接池、3 档候选规模、100%／10% 种子成员可见率、 1／8／32 并发矩阵。MySQL
8.4.11／Redis 7.4.9 为同机临时容器，SQL DEBUG 关闭，单场景 32 个请求， 18 场景共 576 请求成功。测量串行进行，没有同时运行本次回归套件；宿主仍有其他应用活动。

新路径测量包含公开 token 生成，但不包含 HTTP 认证过滤器和前端渲染；旧基线还计算精确 total，新路径将计数拆开。
这是交互路径工作量和产品契约的变化，不是“相同响应功能”下的纯存储类型加速。 尾部只有 32 个样本，且运行时点不同；不能据此承诺生产
SLO 或所有场景都更快。

  当前名称搜索、基础设施失败、创建事实完整性和独立计数。

  token、预算配置和 Unicode 大小写扩展。没有连接业务数据库。
- 前端空间／服务／新版聊天相关测试 69 项通过，覆盖空页后查找、追加、搜索重置、迟到响应、过期恢复及选中空间不受续页改变。
- 新浏览路径基线 1 项通过，内含 576 个响应／工作量断言成功的请求；git diff --check 通过。
- 仓库全量 tsc 有既有类型诊断（134 行输出），本批修改的 workspace 服务、组件及对应集成测试未出现类型诊断；

从 backend 目录使用 JDK 21，按第一批报告启动专用临时实例，改用 13327／16400 端口。确认就绪后运行：

```sh
mvn -o -Pworkspace-baseline -pl arte-app -am \
  -Dtest=WorkspaceDirectoryBaselineTest -Dsurefire.failIfNoSpecifiedTests=false \
  -Dplatform.workspace.baseline=true -Dplatform.workspace.baseline.mode=browse \
  '-Dplatform.test.mysql=jdbc:mysql://127.0.0.1:13327/mysql?serverTimezone=UTC&useSSL=false&allowPublicKeyRetrieval=true&rewriteBatchedStatements=true' \
  -Dplatform.test.redis=redis://127.0.0.1:16400 \
  -Dplatform.workspace.baseline.output=target/workspace-directory-browse.json test

python3 arte-app/scripts/summarize_workspace_baseline.py arte-app/target/workspace-directory-browse.json \
  --output arte-app/target/workspace-directory-browse-summary.json
```
